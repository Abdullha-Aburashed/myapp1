# 📱 MyApp1

A cross-platform mobile application built with **React Native** and **Expo**, with **Firebase** integration for backend services and data management.

---

## 🚀 About the Project

MyApp1 is a mobile application developed for **Android and iOS** using React Native and Expo.

The project demonstrates practical experience with:

* 📱 Mobile application development
* ⚛️ React Native components
* 🧭 Screen navigation
* 🔥 Firebase integration
* 🗂️ Application state management
* 🖼️ Image selection
* 🧩 Reusable components

## 📥 Installation

### 1. Clone the repository

```bash
git clone https://github.com/Abdullha-Aburashed/myapp1.git
```

### 2. Open the project

```bash
cd myapp1
```

### 3. Install dependencies

```bash
npm install
```

---

## 🔥 Firebase Configuration

MyApp1 uses Firebase for backend services and data management.

To configure Firebase:

1. Create a Firebase project.
2. Register your application.
3. Obtain the Firebase configuration.
4. Add the configuration to:

```text
firebaseConfig.js
```

🔒 Keep sensitive credentials and private configuration out of the public repository.

---

## ▶️ Run the Application

Start the Expo development server:

```bash
npm start
```

Run on Android:

```bash
npm run android
```

Run on iOS:

```bash
npm run ios
```

Run in a web browser:

```bash
npm run web
```
